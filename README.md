# Basic CRUD App

A simple Full Stack CRUD application built with Next.js, TypeScript, Prisma, PostgreSQL, and shadcn/ui. This project demonstrates the core CRUD (Create, Read, Update, Delete) operations with a clean and responsive user interface.

-----------------------------------------
✨ Features
----------------------------------
➕ Create new users,
📖 Read and display all users,
✏️ Edit existing user information,
🗑️ Delete users,
⚡ Server Actions for data handling,
🔄 Automatic page revalidation,
📱 Responsive UI with shadcn/ui,
✅ Form validation with Zod.


🛠️ Tech Stack
----------------------------------------
Next.js 15,
TypeScript,
Prisma ORM,
PostgreSQL,
React Hook Form,
Zod,
shadcn/ui,
Tailwind CSS,
